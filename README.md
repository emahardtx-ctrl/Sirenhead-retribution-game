# Siren Head: Retribution - Landing Page y Verificación

Página web de verificación de acceso y zona de descarga para el instalador del juego **Siren Head: Retribution**. Integra flujo de validación de conexión, comprobación de integridad y sistema de verificación humana mediante Google reCAPTCHA v2.

---

## Estructura del Sistema

El proyecto consta de dos módulos principales:

1. **Interfaz Web (GitHub Pages / HTML5 + JS):**
   - Diseño visual temático optimizado para PC y dispositivos móviles.
   - Flujo paso a paso para la comprobación de la sesión del usuario.
   - Integración con Google reCAPTCHA v2 para habilitar la descarga del juego.

2. **Servidor Local de Recepción (Node.js + Express):**
   - Módulo de escucha ejecutado localmente en la computadora.
   - Gestión de solicitudes y conexión mediante túnel seguro con `ngrok`.
   - Archivo local de registros de actividad (`ubicaciones_registradas.txt`).
